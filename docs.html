System Command Documentation

Reference guide for the ternary processor instruction set architecture.

Opcode Mnemonic Glyph Description

Task 0: Maxmimum of two.

Input: two numbers, A >= 0, B <= 728

Output: one number, the greater of A and B.

Task 1: Square root.

Input: one number, 0 <= N <= 255

Output: one number, the square root of N, floored to an integer.

Task 2: Greatest common divisor.

Input: 2 numbers, 0 <= A <= 728, 0 <= B <= 728

Output: one number, the biggest number that both A and B are divisible by.

Task 3: Ternary representation.

Input: 1 number, 100 <= N <= 728

Output: seven numbers, the lower 7 trits of N’s ternary representation, outputted one by one.

Task 4: Next prime.

Input: 1 number, 100 <= N <= 727

Output: one number, smallest prime number that’s bigger than or same as N.
